# 記帳本

家庭用的記帳網頁，放在 GitHub Pages，資料存在 Firebase（Firestore ＋ Authentication，免費的 Spark 方案）。手機和電腦都能用，帳本、清單、行事曆可以用 Email 分享給家人朋友。

## 功能

電腦版用左側選單切換六個分頁，手機版用底部導覽列；帳本、清單點進去的內頁有自己的返回列。

- **帳本**：每本帳本可以挑一隻貓咪當頭像（13 種，新增帳本時三步驟：名稱、顏色與貓咪、分類；之後在帳本設定也能換）。多本帳本（個人、家裡，或孕期、搬家這類有總預算的專案模式）、分類、每月預算、每日／每月圖表、年表、CSV 匯出與匯入。
  - 記一筆：付款方式、信用卡（分期、分期手續費另記一筆、帳單月份可手動改）、付款人（AA 帳本必填，可多人付）、分攤方式（平均／比例／自訂金額／各付各的）、代墊請款、收入。
  - AA 結算、代墊待請款。
  - 帳本設定「信用卡分期記在」：每期帳單月份（預設）或刷卡當月整筆。
- **還款與分期**：貸款（利率、計息方式、校正剩餘本金、推算已繳期數、緩繳本金、最後一期金額）、信用卡帳單（自己的卡、別人名下的卡要轉帳給持卡人、其他人付的；結帳日、繳款截止日、移到下期、標記已轉帳）。
- **資產**：淨資產快照（各帳戶、投資、貸款）、投資持股（平均成本法、股息、手續費設定、扣掉賣出成本的參考現值）、自動帶入台股收盤價。
- **清單**：可分享的清單（例如待產包），分組、排序、買好了順便記帳、親友送禮、已有物品、記事。
- **行事曆**：月曆，自動帶入貸款繳款日、有金額的信用卡繳款截止日、清單截止日；家庭行程可以分享（可編輯／僅檢視）。
- **設定**：外觀（淺色／深色、主題色）、記帳預設值、常用清單、信用卡與持卡人、備份到 Google 雲端硬碟或下載、還原、重看導覽、分享連結。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 所有畫面和對話框 |
| `app.js` | 所有邏輯（ES module，Firebase JS SDK 從 gstatic 載入） |
| `style.css` | 樣式，顏色都用 CSS 變數，有深色模式 |
| `cats/` | 貓咪圖片，每種貓一個資料夾（`cats/orange/face.webp` 是頭像），缺圖時會用橘貓代替 |
| `firebase-config.js` | Firebase 專案設定（不是密碼，資料安全靠安全規則） |
| `firestore.rules` | Firestore 安全規則的留檔；實際生效的是 Firebase 主控台裡的版本 |
| `.github/workflows/quotes.yml` | 每個交易日台灣時間 14:40、18:40 抓台股收盤價 |
| `quotes.json` | 自動產生的收盤價，不要手動改 |

## 第一次設定

1. **建立 Firebase 專案**：到 [Firebase 主控台](https://console.firebase.google.com/) 新增專案（免費的 Spark 方案就夠用）。
2. **開啟登入方式**：Authentication › Sign-in method，開啟「Google」和「電子郵件／密碼」。
3. **建立資料庫**：Firestore Database › 建立資料庫，選正式版模式。
4. **貼上安全規則**：Firestore › 規則，把 `firestore.rules` 的內容整份貼上後按「發布」。
5. **填專案設定**：專案設定 › 一般 › 你的應用程式，新增網頁應用程式，把產生的設定值填進 `firebase-config.js`。
6. **允許網域**：Authentication › 設定 › 已授權的網域，加入 GitHub Pages 的網址（例如 `帳號.github.io`）。
7. **開啟 GitHub Pages**：repository 的 Settings › Pages，來源選 `main` branch 的根目錄。
8. **收盤價**：Actions 頁面確認「更新台股收盤價」已啟用；也可以按「Run workflow」手動跑一次。

## 修改時要注意

- 改到資料欄位時，`firestore.rules` 的 `hasOnly` 清單和檢查要一起改，而且要**先到主控台更新規則，再更新網頁**，不然會出現「沒有權限」。
- 存檔前先拿 GitHub 上最新的版本，因為 GitHub Actions 每天會自動更新 `quotes.json`。
- 改完 `app.js` 可以先複製成 `.mjs` 用 `node --check` 檢查語法。
